# testing

Writing and running tests for a C/C++ project — declaring cases and running them through the build entry point (`xmake test`), which builds the target and applies each case's declared `runargs`/`runenvs`, rather than by launching the built binary path.

| Skill | Topic |
| --- | --- |
| [xmake-tests](./xmake-tests/) | `add_tests` in your project, `xmake test`, gtest/catch2/doctest integration |
