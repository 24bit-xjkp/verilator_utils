# cli

Running xmake from the command line — the `xmake` binary's subcommands, running/cleaning/installing targets, project information and inspection, and project file generation (`xmake project -k …`, see `xmake-commands`). Driving third-party build systems (CMake/Meson/Ninja/…) is not covered in this workspace.

| Skill | Topic |
| --- | --- |
| [xmake-commands](./xmake-commands/) | `xmake f`, `xmake`, `xmake run/install/pack/clean/show`, `xmake project -k …`, common flags |
| [xmake-introspection](./xmake-introspection/) | Inspect targets/deps/packages programmatically, export dependency graphs |
